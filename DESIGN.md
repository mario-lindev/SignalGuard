# SignalGuard visual system

Operate mode: field-oriented pump recording and history. Calm daylight surfaces, readable green ink, large controls and a direct recording workflow. Cream paper (#f6f5ed), forest ink (#173e36), muted green (#52665e), lime accent (#d7ed83). Georgia editorial headings and system UI controls avoid remote font dependencies. Shared spacing 8/16/24/32/48px; 7px control and 12–16px surface radii. Mobile breakpoint 720px stacks the calibration and recording areas. Explicit empty, uncalibrated, busy and error states; visible keyboard focus and reduced-motion support.
